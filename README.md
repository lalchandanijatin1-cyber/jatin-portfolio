## 💻 Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Start a local server

Because the project uses ES modules and assets, it is recommended to run it through a local development server instead of opening the HTML files directly.

For example, with VS Code:

**Live Server → Open with Live Server**

Or use another local HTTP server.

### 4. Open the portfolio

Open the local URL provided by your development server.

Most portfolios follow the same structure:

> About → Skills → Projects → Resume → Contact

I wanted to experiment with something different.

Instead of simply **showing my portfolio**, I wanted visitors to **explore it**.

The idea was to combine my interests in:

**AI + Robotics + Web Development + 3D + Creative Design**

into one interactive experience.
